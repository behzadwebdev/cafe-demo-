# ☕ Cafe Demo — Landing Page

A modern, fully responsive landing page for a coffee shop, built with pure HTML & CSS.

🔗 **[View Live Demo](https://behzadwebdev.github.io/cafe-demo-/)**

## ✨ Features

- 🎨 Modern & cozy design
- 📱 Fully responsive
- 🍰 Menu section with 5 items
- 🖼️ Gallery with 6 images
- 💬 Testimonials from customers
- 📩 Contact form with animations
- 🔤 Custom fonts (Playfair Display + Inter)

## 🛠️ Tech Stack

- HTML5
- CSS3 (Grid, Flexbox, Animations)
- Google Fonts

## 🚀 Getting Started

Open `index.html` in your browser — no setup required.

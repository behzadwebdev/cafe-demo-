# ☕ Cafe Demo — Landing Page

A modern, fully responsive landing page for a coffee shop, built with pure HTML & CSS. Designed with a warm, cozy aesthetic to give visitors a real coffee-shop feeling.

🔗 **[View Live Demo](https://behzadwebdev.github.io/cafe-demo-/)**

---

## ✨ Features

- 🎨 **Modern & cozy design** with a warm coffee-shop color palette
- 📱 **Fully responsive** — optimized for mobile, tablet, and desktop
- 🍰 **Menu section** with 5 items displayed in a single row (horizontal scroll on mobile)
- 🖼️ **Gallery** with 6 high-quality images
- ⏰ **Opening hours** section with clean layout
- 💬 **Testimonials** from happy customers
- 📩 **Contact form** with focus animations
- ✨ **Smooth fade-in animations** on page load
- 🔤 **Custom typography** using Playfair Display & Inter fonts
- ⚡ **Lightweight** — no frameworks, no dependencies

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Semantic structure |
| CSS3 | Grid, Flexbox, Animations |
| Google Fonts | Typography (Playfair Display + Inter) |
